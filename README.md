# LeadPulse Outreach Engine

Python and Streamlit-based outreach engine featuring dynamic page slider, pagination, and automated workflow handling (`master_bot.py`).

## Live App & Repository
- **Live App:** [leadpulse-outreach-engine.streamlit.app](https://leadpulse-outreach-engine.streamlit.app/)
- **GitHub:** [leadpulse-outreach-engine](https://github.com/shaikabdulkhaderjilani/leadpulse-outreach-engine)

## Key Features
- **Dynamic Page Slider & Pagination:** Smooth browsing and paginated navigation across result sets.
- **Automation Workflow (`master_bot.py`):** Core script handling outreach and processing logic.
- **Cloud Ready:** Configured with `requirements.txt` for Streamlit Cloud deployment.
